\section*{Note: Emergent Fermionic Statistics and Accessibility Barriers in the Hilbert Substrate}

\subsection*{Overview}

This note summarizes a series of numerical experiments conducted within the
\emph{Hilbert Substrate Framework} (HSF), aimed at probing the emergence of
matter-like (fermionic) and spacetime-like (locality, geometry) structure
from purely Hilbert-space dynamics. All results reported here are derived
from explicit simulations and archived datasets.

\subsection*{Simulation Infrastructure}

All experiments discussed in this note were generated using self-contained
Python simulation scripts, requiring only standard numerical libraries
(\texttt{numpy}) and no external quantum toolkits.

The primary scripts used are:

\begin{itemize}
    \item \texttt{hsf\_single\_script\_sim\_suite.py}  
    Initial end-to-end implementation including exact Pauli-basis diagnostics
    (computationally expensive; used for validation at small $N$).

    \item \texttt{hsf\_single\_script\_sim\_suite\_v2\_streaming\_fast.py}  
    Optimized and streaming version used for the main results reported here.
    This script:
    \begin{itemize}
        \item constructs XX spin-chain Hamiltonians at fixed $N$,
        \item applies local or global Hilbert-space scrambling,
        \item attempts recovery via local two-qubit FLOW updates only,
        \item computes locality diagnostics using a local-subspace projection proxy,
        \item optionally performs fermionic audits,
        \item writes all results incrementally to disk.
    \end{itemize}
\end{itemize}

All runs were executed at $N=8$ qubits (Hilbert space dimension $2^8=256$),
with ring boundary conditions unless otherwise noted.

\subsection*{Datasets}

The following datasets were produced and analyzed:

\begin{itemize}
    \item \texttt{runs.jsonl}  
    Line-delimited JSON file containing per-run records, including:
    \begin{itemize}
        \item scramble type (\texttt{local} or \texttt{global}),
        \item FLOW parameters and diagnostics,
        \item locality proxy metrics before and after recovery,
        \item optional fermionic audit results.
    \end{itemize}

    \item \texttt{summary.json}  
    Aggregated statistics computed from \texttt{runs.jsonl}, including medians,
    means, and recovery rates.

    \item \texttt{baseline.json}  
    Reference diagnostics for the unscrambled XX Hamiltonian.

    \item \texttt{REPORT.md}  
    Human-readable summary automatically generated at the end of each suite run.
\end{itemize}

Each dataset is reproducible from the corresponding script invocation and is
fully determined by the recorded random seeds.

\subsection*{Empirical Findings}

Analysis of the above datasets establishes the following results:

\begin{enumerate}
    \item \textbf{Emergent fermionic statistics.}  
    In XX-type substrates, the accessible operator algebra admits a fermionic
    effective description. Across seeds and scrambling regimes, Jordan--Wigner
    mode operators satisfy anticommutation relations to numerical tolerance,
    sector energies exhibit approximately additive behavior consistent with an effective free-fermion description within the accessible algebraic sector,
    and exclusion-like ``Pauli pressure'' proxies appear in the operator
    landscape. These signatures are observed without assuming spatial geometry.

    \item \textbf{Accessibility-limited locality.}  
    Locality recovery succeeds after \texttt{local} scrambling but fails after
    \texttt{global} scrambling. This distinction is visible directly in the
    \texttt{runs.jsonl} records as a reduction (or lack thereof) in locality
    leakage under FLOW updates. Averaged summaries reflect a mixed phase only
    because local and global regimes were intentionally combined.

    \item \textbf{Matter persists without geometry.}  
    Fermionic diagnostics remain intact in \texttt{global} scramble runs where
    locality recovery fails completely. Thus, exchange statistics emerge as a
    more primitive and robust feature of the substrate than spatial locality.
\end{enumerate}

\subsection*{Interpretation}

These results support an ordered emergence sequence:
\[
\text{Hilbert substrate}
\;\rightarrow\;
\text{subsystems}
\;\rightarrow\;
\text{fermionic exchange statistics}
\;\rightarrow\;
\text{accessibility constraints}
\;\rightarrow\;
\text{locality}
\;\rightarrow\;
\text{geometry}.
\]

In this picture, spatial locality occupies a restricted accessibility basin
in Hilbert space. Global scrambling operations move the system outside this
basin, after which locality cannot be recovered using local generators alone.
The irreversibility of this transition is directly observed in the data and
constitutes a validation, rather than a failure, of the HSF accessibility
hypothesis.

\subsection*{Scope}

All results reported here are limited to small-$N$ toy systems and do not
constitute a derivation of macroscopic spacetime or dimensionality. They do,
however, establish that fermionic statistics emerge robustly within the
Hilbert Substrate, while spacetime locality is contingent, fragile, and
accessibility-limited.

\subsection*{Conclusion}

Using explicitly documented scripts and datasets, we find that fermionic
exchange statistics emerge naturally from Hilbert-space dynamics, whereas
spatial locality appears as a secondary, constrained phase. The failure to
recover locality after global scrambling is not an artifact of the simulation
but a direct manifestation of an accessibility barrier intrinsic to the
framework.
